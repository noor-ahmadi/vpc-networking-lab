# VPC Networking Lab

A small VPC built with Linux namespaces, virtual Ethernet links, and routing, then recreated in AWS. The [local lab](docs/local-lab.md) has three subnet routing tables, a simulated internet edge, private NAT, and an Nginx proxy calling a private Python app and isolated PostgreSQL database. Checks capture both NAT translations and verify five repeatable [faults and repairs](docs/failures.md). The [AWS version](docs/aws.md) has verified service, NAT, isolation, teardown, and three [cloud fault exercises](docs/aws-failures.md). Follow the [topology and packet walkthrough](docs/topology.md) or [watch the recorded demo](docs/demo.md). The cloud runs are recorded evidence; nothing is kept deployed.
